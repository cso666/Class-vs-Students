# Class vs. Students

Class vs. Students (`CVS`) is an open-source game developed by Floiyd Forging Team and published by Floiyd Studios.

## Run

Install `MinGW` and add it to `Path`.

### Run from Compile.bat

Run:

~~~ batch
start compile.bat
~~~

Waiting for Compilation to complete,then run:

~~~ batch
start main.exe
~~~

## Guidance

Use ^W^ and ^S^ to move the cursor up and down.

Other controls are described in ^说明书.txt^.

Enjoy!
