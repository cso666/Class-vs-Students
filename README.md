# Class vs. Students 游戏说明

## 🎮 这是什么游戏？

这是一款**校园课表回合制策略游戏**。你控制A、B两支学生队伍，在5天×8节课的学校生活中进行3v3对战。每名学生都有独特的**被动/主动技能**、以及**血量(红)/理智(蓝)/体力(白)**三种资源，不同学科会改变战斗局势。

## ⚙️ 如何编译与运行

### 环境要求
- Windows 操作系统  
- MinGW GCC 编译器（https://sourceforge.net/projects/mingw/）  
- 或者任何支持 C++11 的编译环境

### 编译步骤
1. **下载或克隆本项目** 
~~~ batch 
   git clone https://github.com/cso666/Class-vs-Students.git
   cd Class-vs-Students
~~~
2. **使用编译脚本**（最简单）  
   双击运行 `compile.bat`，它会自动调用 g++ 编译并启动游戏。

3. **手动编译**（可选）
~~~ batch  
   g++ -std=c++11 main.cpp -o main.exe
~~~
### 运行游戏
- 编译成功后，直接双击 `main.exe` 或运行 `start.bat`。

> 💡 **提示**：如果杀毒软件报错，请添加信任。因为程序未购买数字签名，属于正常现象。

## 🎯 游戏主体框架

### 1. 游戏流程
- **选人阶段**：系统随机抽取16名学生（共28名），两队轮流挑选5人组成队伍。
- **每日课程**：周一至周五，每天8节课（含晚自习）。
- **每节课**：双方从5人小队中挑选3人进行3回合战斗（晚自习为8回合）。
- **课间恢复**：午/晚饭 +20体力；每节课后 +5理智；周末回满体力、+20理智、血量恢复至20%以上。
- **胜负判定**：5天后剩余人数多的一方获胜；若同时归零则为平局。

### 2. 战斗操作
- **W/S** 键移动光标，**Enter** 键确认选择。
- 每回合可以选择 **普通攻击** 或 **主动技能**（消耗体力/理智）。
- 攻击伤害受多种乘区影响：攻击力 × 攻击倍率 × 目标防御倍率 + 临时攻击加成。
- 伤害有上限（通常30），部分角色或课程可突破上限。

### 3. 资源系统
| 资源 | 名称 | 作用 |
|------|------|------|
| 🔴 红条 | 血量(HP) | 归零则死亡 |
| 🔵 蓝条 | 理智(SAN) | 归零进入**疯人**状态（1.5倍攻击，但随机攻击） |
| ⚪ 白条 | 体力(STA) | 攻击消耗5点；归零进入**力竭**状态（无法行动） |

### 4. 学科效果（部分示例）
每天课程对应不同学科，会触发全队效果：
- **数学**：部分学生获得1.1倍攻击加成，另一些学生体力消耗增加。
- **语文**：随机触发卡牌（双倍伤害、免伤、自伤、回体力）。
- **体育**：扣体力加理智。
- **历史**：不听讲的学生会被老师惩罚，甚至可能直接团灭。
- **物理**：随机标记一名学生，攻击或受击时会波及/治疗他人。
- **英语B**：可能生成“替罪羊”，承担全队伤害。
（其他学科效果详见游戏内图鉴）

### 5. 学生特色
- 28名学生都有**个人词条**（被动）和**主动技能**。
- 例如 A01（小运）：5%概率攻击力+5并晕眩目标；A13（年猪称重）：体力高于70%时可进入强化状态。
- 图鉴（Guidance）中可以查看所有学生的完整技能描述。

### 6. 成就与挑战
- 游戏包含8个进度成就（首次战斗、首次击杀等）和7个挑战成就（全疯模式通关、A5打出30+伤害等）。
- 成就保存在 `achievement.dat` 文件中。

### 7. 设置选项
- **Auto Insane Mode**：所有学生开局直接疯人。
- **Debug Log**：输出战斗日志到 `combat.log`。
- **中文/完整Tips**：调整主界面提示语言和详细程度。
- **Full Roster Mode**：固定使用全部A班或全部B班学生。

## 🎁 彩蛋与提示
- **超能力者 A04-L**：在队伍选人阶段，有 0.1% 的概率自动触发 **超能力者模式**（血量、理智、体力、攻击力全部变为极大值，且获得“神谕”标记）。该角色在战斗中拥有压倒性力量。

- **神谕**：与超能力者 A04-L 同队的学生，有机会获得“深不可测的伟力”临时加成（显示为乱码攻击力）。

- **OIer 游戏**：信息课有 0.1% 概率触发 OIer 计数事件，根据队伍中特定学生（A01、B13、A03、A09、A12）的数量决定胜负，甚至可能双方同归于尽。

- **历史课双杀**：历史课如果两队都有不听讲的学生，有 1% 概率两队全体被老师团灭。

- **图鉴彩蛋**：在图鉴中点击 A04 会切换 ESP 显示模式（仅视觉特效），并解锁“ESP User”成就，但**不会**真的变为超能力者。

- 主菜单会随机显示开发组的有趣 Tips（支持中英文）。

## ❓ 常见问题
**Q：为什么杀毒软件报毒？**  
A：因为程序未购买数字签名，请添加信任即可。

**Q：编译时报错“g++不是内部或外部命令”**  
A：未安装MinGW或未添加环境变量，请先安装MinGW并配置PATH。

**Q：运行时出现乱码？**  
A：请确保使用 `start.bat` 启动（它会设置代码页为65001），或在控制台执行 `chcp 65001`。

**Q：如何查看学生技能？**  
A：主菜单选 **Guidance**，用方向键移动光标查看。
